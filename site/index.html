harness-scan

Lighthouse for your coding agent.

Scans your local Claude Code session history, finds the mistakes your coding agent keeps repeating, and prints a ranked, evidence-backed report — so you can fix your harness instead of correcting the agent by hand forever.

npx harness-scan scan
