Your agent isn't broken. Your harness is.

When a coding agent makes the same mistake twice, the fix isn't a better prompt — it's changing the environment so that class of mistake becomes impossible: a lint rule, a docs pointer, a CI check. That's harness engineering. Almost nobody does it, because almost nobody can see the pattern. It's buried across dozens of session transcripts on disk, one scrollback at a time.

Checklists guess. harness-scan knows.

Most "agent readiness" tools grade your repo against a static checklist — do you have an AGENTS.md, a CI config, a linter. That tells you what should exist. It says nothing about what actually went wrong. harness-scan learns from your agent's real, observed failures instead of guessing from file structure.

One command, five real steps.

1. Locate — finds every Claude Code session transcript on your machine.

2. Extract — locally, no API calls. Flags tool errors, corrections, and retry loops.

3. Summarize — one DeepSeek call per session turns candidates into specific, one-sentence failures.

4. Cluster — one more call groups failures across every session into ranked, named patterns.

5. Report — ranked, evidence-backed, with a concrete suggested fix for each. No black box: read exactly what each step does in the source.
