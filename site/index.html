Find your coding agent's recurring failures

harness-scan is a free, open-source CLI that scans your local Claude Code session history and prints a ranked report of the mistakes your agent keeps repeating — so you can fix your harness instead of correcting the agent by hand forever.

It's also built right into runwright: upload a session transcript export, and runwright installs harness-scan from npm inside its own sandbox and runs the exact same scan. No local install, and never a live connection to your machine.

Security decided up front — not bolted on

No raw tokens in the sandbox

Connectors work through a short-lived, signed proxy token. The real OAuth token exists only inside runwright's own server, never in agent-generated code.

Secrets, name-only to the model

The agent sees a secret's name so it can reference it in code — never the value. Values are decrypted only at run time, injected straight into the sandbox.

Every run ends honestly

No silent retries, no swallowed errors. Every execution reports a real exit code with the actual output and logs, visible to you.
